# Projeto-Individual---A-arte-de-conversar
Desenvolver um site informativo sobre a arte de conversar, utilizando como base os ensinamentos do livro. Apresentar conceitos fundamentais de comunicação interpessoal. Demonstrar técnicas para melhorar a convivência social. Auxiliar pessoas que possuem dificuldade em se comunicar. Compartilhar aprendizados adquiridos com a leitura do livro.
